## Review (s244-linguist-reviewer)

All 183 strings read against EN, scene and speaker. Grammar, suffix and vowel harmony (işaretçi/işaretçisi/işaretçinin/işaretçiyle/işaretçideki, hac yolculuğum/-un/-umuz, asari'ye/'yle/'yse, telkin) are correct in every one; none rejected. Verdicts on the "unsure" items:

- Non-Prothean beacons (u20043, u20046, u21521, u21537, u23428 item names; u15464, u15478, u15745, u15746 Alliance and distress beacons; u22839, u23236, u23248 Porolan and collectibles; u22604 Geth trap; u27816, u27827, u27836 barks): accepted. One word for one object class keeps the codex and quests consistent; no better short Turkish word exists that also fits the ui.
- u10474 "hac yolcusu": accepted (natural plural-subject use).
- Feros creepers without Thorian (u16679, u16713, u24849-u24852, u25061): accepted, glossary rule (sarmaşık).
- Fix 5 (u00199, u00238, u00351, u08632, u09141, u19264): accepted. u09141 changed: the editor's "girdi" -> "kapıldı" repeated the first "kapıldı" (swept up), so the first one is now "sürüklendi".
- Left as is on purpose: u26606/u26630 map markers, u17936 "fener", u10220 flare ("işaret fişeği" for a flare is correct), u17576 and u11352 etc. (mind control and "take control", not indoctrination).
